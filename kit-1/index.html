Voiture - photos spécimens fictives pour les tests

Données de test uniquement. N'envoyez jamais de vraie pièce d'identité, de vrai permis ni de vraie carte grise : utilisez seulement les photos de cette page.

Enregistrer les photos sur le téléphone

  1. Sous chaque photo, touchez « Enregistrer la photo » : elle va dans les Téléchargements du téléphone.
  2. Dans DJOUMO Chauffeur, touchez « Ajouter une photo », puis « Choisir dans la galerie », et choisissez la photo indiquée (album « Download » ou « Téléchargements »).
  3. Votre fiche de kit indique quelle photo envoyer pour chaque document.
Tout télécharger (fichier ZIP)

Le fichier ZIP (0,5 Mo) est pratique sur un ordinateur ; sur le téléphone, enregistrez plutôt les photos une par une.
